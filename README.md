# Production Boost (FS25)

Speed up any production line in Farming Simulator 25: 1x, 2x, 5x or 10x.

- Tick boxes ("PRODUCTION LINE BOOST %") in the Production Chains menu, one setting per production line.
- The boost multiplies cycles and running costs; the recipe per cycle stays the same.
- Storage capacity (incoming and outgoing) grows by the same factor, following the highest boost on that production.
- Works with base game, map and mod productions. Multiplayer: only the farm manager can change it. Saved with the savegame.

See [PATCH_NOTES.md](PATCH_NOTES.md). Author: PropaineX.
